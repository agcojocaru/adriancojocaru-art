Drop your diary images into this folder.

Name them like this:
  2024-03-22-bucharest-street.jpg
  2024-03-15-studio-detail.jpg
  2024-02-08-color-study.jpg

The site rebuilds automatically on Netlify whenever you add a new image.
Newest image (highest date) appears first.

Optional captions:
  Create a .txt file with the same name as your image:
  2024-03-22-bucharest-street.txt → contents become the caption

  If no .txt file exists, the caption is derived from the filename.

Delete this README.txt before going live (or leave it — it won't affect anything).
